# Flow

*Flow* es una aplicación de planificación de tiempo con tareas y vistas en un
calendario. Está escrita en Angular con la librería Material UI.

## Funciones

- Calendario interactivo
  - Modo mes, semana y agenda diaria
- Crear, modificar y eliminar tareas
- Actualizar estados de tareas
- Listado de tareas pendientes
- Historial
- Notificaciones antes y cuando termina una tarea
